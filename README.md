## 🚀 Featured Projects

💡 *Projects I built end to end, from the data model to the interface:*

### 🔑 Keychain ERP <sub>· In use for over a year, with AI</sub>

A management system I built on my own for my family's business: catalog, customers, orders, inventory and revenue.

<table>
  <tr>
    <td align="center"><h3>97.3%</h3><sub>accuracy on 10 real slips</sub></td>
    <td align="center"><h3>0</h3><sub>invented products</sub></td>
    <td align="center"><h3>−63%</h3><sub>order entry time</sub></td>
    <td align="center"><h3>US$0.05</h3><sub>per slip</sub></td>
  </tr>
</table>

* **AI order reader:** a photo of a handwritten order slip becomes a draft order. The AI can only choose registered products and customers, flags its doubts, and nothing is saved without human review.
* **Reliable data:** the catalog is the source of truth, and each order is saved in an atomic transaction that validates and deducts stock.
* **Stack:** React, Firebase, Material UI, Claude API and Vercel Functions.

### 📈 Personal Finance App <sub>· Full Stack project, in progress</sub>

A personal finance application built end to end, focused on architecture and quality.

* **Back end:** REST API with Node.js, Express, Prisma ORM and PostgreSQL, with per-user data isolation.
* **Architecture:** use cases, repositories and factories, following SOLID principles and dependency injection.
* **Authentication:** JWT with access and refresh tokens; on the front end, an Axios interceptor renews the session automatically.
* **Quality:** integration tests with Jest and Supertest, CI on GitHub Actions, Docker, ESLint, Prettier, Husky and Commitlint.
