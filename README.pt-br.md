## 🚀 Projetos em Destaque

💡 *Aqui estão alguns dos projetos recentes que desenvolvi com foco em escalabilidade e boas práticas:*

### 📈 [Personal Finance App](SEU_LINK_DO_REPOSITORIO) (Projeto Full Stack)
Uma aplicação completa para gerenciamento financeiro pessoal, construída com forte foco em arquitetura de software e escalabilidade.
* **Back-end:** REST API desenvolvida com Node.js, Express, Prisma ORM e PostgreSQL.
* **Arquitetura:** Baseada estritamente nos princípios SOLID e Injeção de Dependência.
* **Qualidade:** Implementação de autenticação, validação de dados, testes automatizados e padronização com ESLint, Prettier, Husky e Commitlint.

### 🔑 [Keychain ERP](SEU_LINK_DO_REPOSITORIO) (Sistema em Produção)
Sistema de gestão de vendas completo com dashboards, controle de estoque e análise de metas.
* **Estado Global:** Uso de Context API para gerenciamento de estado global, evitando prop drilling e melhorando a escalabilidade.
* **Lógica Reutilizável:** Criação de custom hooks para encapsular a lógica de negócios da aplicação.
* **Banco de Dados:** Integração direta com o Firestore para gerenciamento de todas as operações de CRUD.
